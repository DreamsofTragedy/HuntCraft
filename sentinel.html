Table and field mapping notes

CommonSecurityLog uses SourceHostName, SourceIP, DestinationHostName and DestinationIP. SecurityEvent commonly uses WorkstationName, IpAddress and Computer; it may not provide a destination IP. SigninLogs uses IPAddress and UserPrincipalName. Use blank mappings for fields your table does not provide. Tables and columns depend on your connectors.

IOC search

IPs · URLs · SHA-256

Match indicators in mapped log fields. Indicators within each type use OR.

IOC filters are ANDed with the current scope and other filters. The button clears condition/endpoint filters, retaining scope, time and IOC input. URLs match the complete value and preserve path/query case; hashes ignore letter case. URLs must be one per line; IPs/hashes can also use commas. Blank mappings need configuration for any populated IOC type. Choose a table/event type containing those fields; mixed IOC types may require separate searches. This tool never visits the indicators.

Query notes

Contains is a case-insensitive substring match; equals is case-sensitive. Present/missing checks use isnotempty() / isempty(). String values are quoted and numeric comparisons use numbers. Local checks validate builder inputs; they do not verify table schemas or execute queries in Sentinel.
