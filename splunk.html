Field mapping examples

Network/CIM-style logs may use src_ip / dest_ip. Sysmon Event 3 commonly uses SourceIp / DestinationIp and SourceHostname / DestinationHostname. Authentication logs may use IpAddress / WorkstationName. Splunk's host field identifies the event's reporting host; it is not always the connection source or destination.

IOC search

IPs · URLs · SHA-256

Match indicators in mapped log fields. Indicators within each type use OR.

IOC filters are ANDed with the current scope and other filters. The button clears condition/endpoint filters, retaining scope, time and IOC input. URLs match the complete value and preserve path/query case; hashes ignore letter case. URLs must be one per line; IPs/hashes can also use commas. Blank mappings need configuration for any populated IOC type. Choose a table/event type containing those fields; mixed IOC types may require separate searches. This tool never visits the indicators.

Query notes

“Contains” uses search wildcards. “Not equal” excludes matching values and events without that field. “Exists” emits field=*. Local checks verify builder inputs; they do not parse SPL or validate it against your Splunk instance.
