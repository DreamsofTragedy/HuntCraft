QRadar field mapping notes

Events and flows provide sourceip / destinationip. Source and destination hostnames may be custom properties or asset enrichment, so their mappings are blank by default. Enter the exact custom property name when available. Custom names with spaces are quoted automatically. Flow searches use firstpackettime; event searches use starttime. Confirm property availability for your DSM and data source.

IOC search

IPs · URLs · SHA-256

Match indicators in mapped log fields. Indicators within each type use OR.

IOC filters are ANDed with the current scope and other filters. The button clears condition/endpoint filters, retaining scope, time and IOC input. URLs match the complete value and preserve path/query case; hashes ignore letter case. URLs must be one per line; IPs/hashes can also use commas. Blank mappings need configuration for any populated IOC type. Choose a table/event type containing those fields; mixed IOC types may require separate searches. This tool never visits the indicators.

Query notes

Contains uses ILIKE with % wildcards; % and _ within your input are patterns too. Payload conditions and columns use UTF8(payload). Present/missing checks use IS NOT NULL / IS NULL. This version rejects apostrophes and line breaks inside string values; use the editable preview for advanced literals. Local checks do not validate against a live Ariel database.
